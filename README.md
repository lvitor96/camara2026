# Câmara 2026

App de estudo para o concurso da Câmara dos Deputados (Analista Legislativo, cargo 11): plano, questões com grau de certeza, caderno de erros com revisão espaçada, ensaios com nota P1/P2 e desempenho.

- Hospedagem: GitHub Pages (este repositório só tem o código).
- Dados: Firebase (projeto `camara2026-abdb6`), acessíveis só pela conta do dono. O banco de questões **não** está neste repositório: é importado pelo próprio app em Ajustes.
